# ToPersia User Core — راهنمای توسعه

نسخهٔ فعلی: **۱٫۱۰٫۳**
جایگاه: افزونهٔ حساب کاربری دانشنامهٔ ToPersia — ورود با پیامک، پنل کاربر، مکان‌های ذخیره‌شده.

---

## جایگاه در استک

سه افزونه داریم و مرزشان روشن است:

| افزونه | مسئولیت | این افزونه چه چیزی از آن می‌گیرد |
|---|---|---|
| `topersia-core` | نوع پست‌ها، روابط، شِما، **ثبت رویداد**، اسکلت جغرافیایی | `topersia_log()` · `topersia_admin_css()` · منوی `topersia` |
| `topersia-render` | قلم، پالت سه‌حالته، پل تم، پنل خوانایی | توکن‌های `--tp-*` برای رنگ پنل کاربری · خبرِ «دنبال‌شده‌ها» از فیلتر `topersia_entity_latest_news` (اختیاری؛ بی آن، «خبر تازه‌ای نیست») |
| `topersia-user-core` | **این افزونه** | — |

**قاعده:** وابستگی همیشه رو به هسته است، هرگز برعکس. هر فراخوانی به توابع دو افزونهٔ دیگر باید با `function_exists()` گارد شود؛ افزونه باید بدون آن‌ها هم بالا بیاید، حتی اگر ظاهرش ساده‌تر شود.

## قواعد کدنویسی

**هرگز وصله نده — همیشه فایل کامل.** قانون اول پروژه. تغییر جزئی هم به‌صورت فایل کامل و مرتب تحویل می‌شود.

**هیچ‌گاه حدس نزن، از داده بخوان.** پیش از هر ادعا دربارهٔ ساختار، فایل اصلی یا export زنده را مستقیم بخوان. نام کلید، امضای متد و مسیر نوشتن هیچ‌کدام حدس‌کردنی نیستند.

**هر فراخوانی بیرونی گارد می‌خواهد — شامل توابع خود وردپرس.** روی این هاست `error_log()` و `mail()` غیرفعال‌اند. `error_log` قبلاً در همین پروژه خطای مرگبار داد. برای ثبت رویداد فقط از این استفاده کن:

```php
if ( function_exists( 'topersia_log' ) ) {
    topersia_log( $message, 'error', 'user', [ 'file' => $e->getFile() ] );
}
```

**کد خاموش، کد آزموده نیست.** مسیری که اجرا نشده «سالم» نیست، فقط خاموش است. فعال‌کردن یک مسیر خاموش یعنی کد تازه.

**ویژگی CSS را دست‌کم نگیر.** سه بار در این پروژه قاعده‌ای با ویژگی ۰٬۱٬۰ نوشتیم و قاعدهٔ هم‌وزنِ دیرترِ وودمارت آن را برد. برای هر چیزی که باید قطعاً اعمال شود، پیشوند `html:root` بگذار.

## زبان و ترجمه

متن رابط فارسی است و از `__()` با دامنهٔ `topersia-user-core` می‌آید. عنوان تب‌ها سه‌زبانه در آپشن ذخیره می‌شوند و با `wpml_register_single_string` به WPML معرفی می‌شوند.

**هر متنی که روی صفحهٔ عمومی دیده می‌شود از واژه‌نامهٔ سه‌زبانه است** — `ToPersia_I18n::t( 'کلید' )`، fa · en · ar کنار هم در `class-topersia-i18n.php`: پنل، پنجرهٔ ورود، فرم ورود پیامکی و هر پیامی که AJAX به صفحه برمی‌گرداند (۱٫۱۰٫۳). دامنهٔ `topersia-user-core` کاتالوگ انگلیسی و عربی ندارد؛ `__()` آن روی صفحهٔ انگلیسی فارسی می‌ماند. کلاس احراز هویت پیام را از `ToPersia_Auth::msg( 'کلید', 'فارسی' )` می‌گیرد تا بی واژه‌نامه هم بار شود (هارنس `SECURITY.md`).

**Classic Translation Editor الزامی است** — Advanced Translation Editor جمله‌ها را در سطح جمله می‌شکند و برای این پروژه ممنوع است.

## نکته‌های ویژهٔ خط فارسی

`letter-spacing` روی متن فارسی ممنوع است؛ اتصال حروف را می‌شکند. برای همان نیاز از `word-spacing` و `line-height` استفاده کن.

عدد در فرانت با جداکنندهٔ فارسی `٬` و ورودی ادمین بدون جداکننده.

کاراکتر «ۀ» همیشه `U+06C0` یکپارچه، نه ترکیب دو codepoint.

## آزمون پیش از تحویل

هر تغییر باید این سه را بگذراند:

```bash
find . -name "*.php" -exec php -l {} \;   # نحو
node --check assets/js/user-core.js       # نحو جاوااسکریپت
node --check assets/js/admin.js
```

و برای هر تغییر در مسیر احراز هویت، شبیه‌سازی محدودیت نرخ و سقف حدس را دوباره اجرا کن. سناریوها در `SECURITY.md` بخش «آزمون‌ها».

## API برای «هستهٔ نمایش» — ۱٫۱۰٫۰

ذخیره، دنبال‌کردن، نظر و پنجرهٔ ورود/ثبت‌نام **مال همین افزونه‌اند**. «هستهٔ
نمایش» فقط دکمه می‌سازد و از این دو در عبور می‌کند؛ هیچ نسخهٔ موازی نسازد:

| در | کار |
|---|---|
| `ToPersiaUserCore.call(action, data)` | همان `ajax()` داخلی — نانس و نشانی یک‌جا |
| `ToPersiaUserCore.openLogin({reason, redirect})` | پنجرهٔ ورود، با دلیل و بازگشت به همان صفحه؛ رویداد `topersia:login-required` هم همین است |

نقاط تازه: `topersia_follow_entity` · `topersia_entity_state` · `topersia_submit_review`
— جزئیات در `ARCHITECTURE.md`. شناسهٔ ذخیره، دنبال و نظر همیشه **زبان پیش‌فرض**
WPML است.
